# Exercise 1-2: Installing Protégé

**In this exercise, you will learn how to download, install, and start the Protégé ontology editor.**

Protégé is a free, open-source ontology editor developed at Stanford. It is one of the most widely used tools for creating and editing ontologies in the Web Ontology Language (OWL), and it is the primary ontology-development tool used throughout this book.

If you already have Protégé installed, it is still worth checking your installation before continuing. The exercises in this book assume **Protégé 5.6.9 or later**, along with several configuration changes and plugins introduced in the next exercise.

If you already have an appropriate version installed, you can skip the installation steps and continue with the exercise on loading plugins and configuring Protégé.

## Step 1: Go to the Protégé Website

Open the [Protégé website](https://protege.stanford.edu/).

**Click `Download Now`.**

The Protégé website should direct you to the appropriate download options.

## Step 2: Select the Desktop Version

Protégé is available for multiple operating systems. The examples in this book were created using Windows, but the desktop version of Protégé can also be used on other supported operating systems. The interface should be very similar.

You may also see an option for **WebProtégé**.

WebProtégé is useful for collaborative ontology development and will be discussed later in the book. However, the exercises in this book require capabilities available in the desktop version of Protégé, including reasoning support.

**Download the desktop version of Protégé for your operating system.**

## Step 3: Install Protégé

After the download completes, locate the downloaded installation file.

**Double-click the downloaded file to begin the installation.**

The installer may ask you to confirm several installation options.

**Accept the default installation options unless you have a specific reason to change them.**

## Step 4: Start Protégé

After installation is complete, locate the Protégé application or shortcut.

**Double-click the Protégé icon to start the editor.**

Protégé should open and display its main ontology-editing interface.

✅ At this point, Protégé is installed and running.

## Step 5: Consider Joining the Protégé Support Community

If you plan to use Protégé to create and maintain ontologies, not just to view the examples in this book, the Protégé user community can be a useful resource.

Visit the [Protégé Support page](https://protege.stanford.edu/support).

From there, you can find information about Protégé and WebProtégé support resources, including the user mailing list.

## Next Step

You now have the Protégé desktop editor installed.
